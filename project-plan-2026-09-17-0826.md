## Goal

Add On-Policy Entropy Flow Optimization (OPEFO, arXiv:2605.11491) to ECHO for both `high_level` and `low_level` phases. When enabled, replace the clipped PPO PG loss with the paper's on-policy `-log_prob · A` loss reweighted by adaptive `λ*` from Theorem-1 token entropy flow `ΔH`. Default remains off so existing GRPO runs are unchanged. Emit phase-prefixed `opefo_*` wandb metrics.

```
phases.*.opefo.enabled
  -> echo_ray_trainer (meta_info["opefo_enabled"])

       |-- false -> compute_policy_loss (unchanged clipped path)
       |-- true  -> logits forward -> compute_delta_H_theorem1 (no_grad)
```

## Locked decisions

- **Scope:** both `high_level` and `low_level`.
- **Loss form:** paper OPEFO path `pg = -log_prob * A`, then rescale by `(1±λ*)` on `S+/S-`. Existing clipped PPO path stays untouched; switch via config.
- **ΔH:** full Theorem 1 / Eq. 6 over the vocabulary (not a sampled-token proxy). Learning-rate `η` omitted (cancels in `λ*`; equivalent to `η=1`).
- **Metrics:** log OPEFO diagnostics to wandb through the existing phase-prefixed actor metrics pipeline.
- **Constraint:** OPEFO needs raw logits → assert `use_fused_kernels=false` when enabled. Prefer computing ΔH on rmpad logits then pad ΔH back.
